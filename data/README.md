# Project Data

This directory contains synthetic data prepared for the public demonstration
of the Pharmacy Business Intelligence & Data Warehouse project.

## Public Data

The datasets included here are synthetic and do not contain the original
patient or laboratory records used during the academic project.

### Files

- `Bi_Db_Datamarts_synthetic.csv`
  - Synthetic examination, organization, date, revenue, and request data.

- `Bi_Db_Datamarts_2_synthetic.csv`
  - Synthetic patient demographic, date, revenue, and request data.

## Privacy

The original academic project used real laboratory/healthcare data.

For privacy and confidentiality reasons, the original records are not
distributed in this repository.

The datasets provided here are intended only for demonstration,
portfolio presentation, and reproducibility.

These datasets can be imported into Microsoft Power BI or another
data-analysis tool for demonstration purposes.
