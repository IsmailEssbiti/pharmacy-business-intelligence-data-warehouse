# BI_Pharmacie_CUBE — SSAS Multidimensional Cube

This folder contains the public, sanitized SQL Server Analysis Services (SSAS) project for the BI_Pharmacie Business Intelligence project.

## Components

- **Data source:** `Bi Db Datamarts.ds`
- **Data source view:** `Bi Db Datamarts.dsv`
- **Cube:** `Bi Db Datamarts.cube`
- **Partitions:** `Bi Db Datamarts.partitions`
- **Dimensions:** Compte, Date, Exam, Organization, Paiement, Patient
- **Database definition:** `BI_Pharmacie_CUBE.database`

## Setup

1. Create and populate the `bi_db_datamarts` SQL Server database using the project's SQL scripts.
2. Open the SSAS solution in SQL Server Data Tools (SSDT).
3. In `Bi Db Datamarts.ds`, replace `YOUR_SQL_SERVER_INSTANCE` with your SQL Server instance.
4. Configure the Windows account used for data-source impersonation if required by the local SSAS environment.
5. Build the project.
6. Deploy the `BI_Pharmacie_CUBE` database to a local/development SSAS instance.
7. Process the cube before using it from a reporting client such as Power BI.

## Public Repository Data

The SSAS cube model is provided as a technical demonstration of the
multidimensional reporting layer.

The original project data is not included in this public repository.

The cube should be deployed against a compatible data-mart environment
containing synthetic or appropriately anonymized data.

## Excluded build/user files

The repository intentionally excludes generated or machine-specific files such as:

- `bin/`
- `obj/`
- `*.suo`
- `*.user`
- `*.asdatabase`
- `*.configsettings`
- `*.deploymentoptions`
- `*.deploymenttargets`

These files are generated by the SSAS build/deployment process and are not required as source files for the public project.
